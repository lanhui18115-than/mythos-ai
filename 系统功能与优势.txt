一、系统定位
──────────────────────────────────────────────────────────────────────────────

Mythos AI 不是一个普通的神话百科或通用 AI 聊天机器人。
它是一个以权威教材为核心的、面向英语语言文学本科生的 AI 辅助教育系统。

核心原则：Textbook First, AI Second.
  - 所有核心知识来源于同一本教材（Morford, Lenardon, Sham, Oxford UP）
  - AI 仅用于组织、检索、解释和生成学习活动
  - AI 从不编造神话事实，从不混入外部未经验证的知识
  - 每条知识点都可回溯到教材的具体章节和页码

================================================================================

二、整体架构（四层设计）
──────────────────────────────────────────────────────────────────────────────

  Layer 4: AI Tutor
    学生提问 → 知识图谱检索 → DeepSeek LLM 组织回答 → 返回并标注出处
    支持在线模式（LLM 自然语言回答）和离线模式（本地关键词检索，自动降级）

  Layer 3: 学习活动层
    6 个学习模块：测验 / 填字游戏 / 艺术品识别 / 家族树 / 角色索引 / 学习中心
    所有活动来源于知识图谱，不产生新知识，保证内容一致性

  Layer 2: 知识图谱
    1010 个角色、402 个神话、390 个地点、433 个概念、206 件艺术品
    3340 条关系，每条关系标注教材章节和页码
    分类明确：神祇/英雄/凡人/怪物/泰坦/宁芙等

  Layer 1: 教材原文
    classical_myth.pdf（38 MB 压缩版）
    按 24 章拆分为独立 PDF（每章 0.7~3.5 MB），支持快速加载和页码跳转

三、功能模块详解
──────────────────────────────────────────────────────────────────────────────

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 1：首页（index.html）                                                  │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 系统全局导航入口
  - 实时数据统计：24 章 / 1010 角色 / 402 神话 / 390 地点 / 433 概念 / 206 艺术品 / 3340 关系
  - 6 个功能模块的卡片式入口，每个卡片标注状态（ready）、文件大小、生成脚本
  - 一键重新生成所有学习活动（管理员功能）

教育优势：
  - 学生一打开就能看到系统的知识规模，建立信任感
  - 清晰的导航结构，零学习成本

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 2：学习中心（learning_center.html）                                    │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 三栏式布局：左侧章节列表 / 中间 PDF 阅读器 / 右侧信息栏
  - 三个 Tab：Reader（PDF 阅读）/ Summary（章节摘要）/ Quiz（章节测验）
  - PDF 阅读器：24 章按章节拆分，每章 0.7~3.5 MB，点击即加载并跳转到该章起始页
  - 工具栏显示当前章节的印刷页范围和 PDF 页码
  - "Open PDF in New Tab" 在新标签页打开当前章节 PDF
  - Summary Tab：章节摘要、关键角色列表、相关神话、相关艺术品、重要概念
  - Quiz Tab：每章 3 套测验卷，每卷 10 题，含选择题/判断题
  - 深色/浅色模式切换（与全局同步）

教育优势：
  - 教材阅读与测验无缝衔接：读一章 → 做一章测验，无需切换页面
  - 按章节拆分 PDF：加载速度快（不等待整本教材下载），且自动定位到章节起始页
  - 章节摘要提炼核心知识点，帮助学生抓住重点
  - 知识点与教材页码一一对应，学生可随时回到原文验证

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 3：角色索引（character_index.html）                                    │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 1010 个角色的全文搜索（支持中英文、希腊名、罗马名、异体拼名）
  - 分类筛选：全部 / 神 / 女神 / 英雄 / 凡人 / 怪物 / 泰坦 / 宁芙 / 其他
  - 每个角色的完整信息卡片：
    · 希腊名 + 罗马名
    · 称号列表（Epithets）
    · 管辖领域（Domains）
    · 象征物（Symbols）
    · 角色描述
    · 家族关系（父母、配偶、子女、兄弟姐妹）
    · 相关神话列表（附摘要）
    · 相关艺术品列表（含图片）
    · 教材出处（章节 + 页面引用）
  - 角色详情中的"家族树"链接可直接跳转到家族树并定位到该角色
  - 角色卡片可展开/收起，不占用页面空间
  - 搜索结果实时显示，输入即搜索
  - 深色/浅色模式切换

教育优势：
  - 教材导向：每个角色信息都有教材出处，学生可直接溯源
  - 双向关联：角色 → 关联神话 + 关联艺术品 + 家族关系，形成知识网络
  - 角色索引 ↔ 家族树 双向跳转，帮助学生理解角色之间的关联
  - 支持异体拼名搜索（解决学生记不住准确拼写的问题）

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 4：家族树（family_tree.html）                                          │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 基于 vis-network 的交互式可视化图谱
  - 节点类型按颜色区分：神祇 / 英雄 / 凡人 / 怪物 / 泰坦
  - 关系类型按线条区分：父母 / 配偶 / 子女 / 兄弟姐妹
  - 搜索角色：输入名称自动定位并高亮该节点
  - 点击节点：显示角色详情 + 关系列表 + 教材证据
  - 角色详情中的"详细信息"链接可跳转到角色索引
  - 节点可拖拽，图谱可缩放平移
  - 分类筛选：只显示特定类型的角色
  - 打开时自动定位到宙斯家族（核心家族）
  - 深色/浅色模式切换

教育优势：
  - 直观展示神话中最复杂的家族关系（希腊神话以乱伦关系复杂著称）
  - 可视化学习比文字描述更易理解家族谱系
  - 每个关系都有教材引用，学术严谨
  - 家族树 ↔ 角色索引 双向跳转，形成完整的学习闭环

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 5：知识测验（quiz.html）                                               │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 四种题型：选择题、判断题、匹配题、简答题
  - 按章节选择题目范围
  - 每题包含：
    · 题目描述
    · 选项/输入框
    · 提交后显示对错
    · 正确答案
    · 详细解释
    · 教材出处（章节 + 页码）
  - 自动计分
  - 匹配题采用拖拽式匹配
  - 简答题展示参考答案 + 评分标准
  - 题目可随机抽取，每卷 10 题
  - 深色/浅色模式切换

教育优势：
  - 所有题目来自教材知识图谱，不超纲、不编造
  - 每题都有出处，学生答错后可回到教材原文学习
  - 四种题型覆盖不同认知层次：
    · 选择题 → 识记
    · 判断题 → 辨析
    · 匹配题 → 关联
    · 简答题 → 表达

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 6：填字游戏（crossword.html）                                         │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 自动生成填字网格
  - 词条来源：希腊名、罗马名、称号、地点、神话术语
  - 键盘导航：方向键移动、空格切换方向
  - 线索面板：Across / Down 分组显示
  - 当前线索高亮显示
  - Check 按钮检查已填答案
  - Hint 按钮提示当前格
  - Reveal 按钮显示全部答案
  - New Puzzle 生成新游戏
  - 深色/浅色模式切换

教育优势：
  - 游戏化学习，提升学习趣味性
  - 线索设计引导回忆角色名称和神话概念
  - 强化记忆：拼写过程加深对名称的印象
  - 适合课堂互动或课后自学

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 7：艺术品识别（artwork_quiz.html）                                     │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 基于教材中 206 件艺术品
  - 三种题型：
    · 角色识别：根据艺术品描述或图片判断描绘的角色
    · 类型判断：判断艺术品的类型（雕塑/瓶画/壁画/马赛克等）
    · 描述匹配：将艺术品描述与名称匹配
  - 图片来源：教材 PDF 提取的图片（已压缩至 99 MB）
  - 图片可点击放大查看
  - 每题回答后显示出处和解释
  - 深色/浅色模式切换

教育优势：
  - 连接视觉艺术与文学知识，跨学科学习
  - 古典神话与古希腊罗马艺术紧密结合
  - 培养学生识别艺术品中神话场景的能力

┌──────────────────────────────────────────────────────────────────────────────┐
│ 模块 8：AI Tutor — 智能助教                                                │
├──────────────────────────────────────────────────────────────────────────────┤

功能：
  - 页面右下角浮动按钮，点击展开聊天面板
  - 两种工作模式：
    · 在线模式（默认）：RAG 检索 → DeepSeek LLM 生成自然语言回答
    · 离线模式（降级）：RAG 检索 → 关键词匹配返回结构化结果
  - 支持中英文双语提问
  - 回答格式：
    · 人物查询 → 身份 + 罗马名 + 称号 + 领域 + 相关神话 + 教材出处
    · 神话查询 → 摘要 + 关键人物 + 教材出处
    · 概念查询 → 定义 + 教材出处
    · 地点查询 → 描述 + 教材出处
    · 艺术品查询 → 描述 + 教材出处
  - 引用标注：每条信息标注教材章节和页码（Ch.N pp. XX-XX）
  - 上下文理解：在线模式下记住对话历史，可连续追问
  - 聊天记录自动保存（localStorage），关闭页面不丢失
  - 清空对话功能
  - 搜索索引预加载：首次打开面板时加载 1.5 MB 索引

教育优势：
  - 从不编造：所有回答基于教材知识图谱，学生获得的信息均可信
  - 培养溯源习惯：AI 每句话都标注出处，学生学会查证原文
  - 降低提问门槛：即使记不住准确名字，也可以模糊提问
  - 双语支持：适应国际化教学需求
  - 离线也能用：没有网络时自动降级为本地搜索

四、核心技术优势
──────────────────────────────────────────────────────────────────────────────

4.1 知识图谱驱动
  - 3340 条关系构成的关联网络，而非孤立的条目列表
  - 可以回答"谁和谁有关"、"什么神话涉及什么角色"这类关联性问题

4.2 教材溯源体系
  - 每条关系、每个知识点都记录教材章节和页码
  - 知识分三级：
    Level 1 Explicit — 教材明确陈述（优先使用）
    Level 2 Implicit — 教材可合理推导
    Level 3 Supplementary — 外部学术信息（仅作为可选拓展）

4.3 RAG 检索增强生成
  - AI Tutor 不是直接用 LLM 记忆回答，而是先检索知识图谱再生成
  - 保证回答的事实准确性，减少 AI 幻觉

4.4 纯静态前端 + 可选后端
  - 7 个 HTML 页面 + 1 个 JS 组件 = 完整系统
  - 无需服务器就能运行全部功能（AI Tutor 自动降级）
  - 可部署到任何静态托管服务（GitHub Pages、Vercel、Netlify）

4.5 深色/浅色主题
  - 所有页面支持深色/浅色模式切换
  - 适应不同使用环境和用户偏好
  - 设置保存在 localStorage，跨页面保持一致

4.6 双向页面跳转
  - 角色索引中的家族关系可跳转到家族树并定位角色
  - 家族树中的角色可跳转到角色索引查看详情
  - 学习中心章节摘要中的实体链接可跳转到角色索引
  - 知识网络完整闭合

七、总结
──────────────────────────────────────────────────────────────────────────────

Mythos AI 的定位不是"另一个神话百科全书"，而是一个"教材数字化教育系统"。

其核心价值在于：
  1. 让教材活起来 — 静态的 PDF 变为可交互、可搜索、可关联的数字学习空间
  2. 让 AI 服务于教育 — AI 不是替代教材，而是帮助学生更好理解教材
  3. 让学习可追溯 — 每个知识点都有来源，培养学术严谨性
  4. 让学习更有趣 — 测验、填字、艺术品识别等游戏化模块
  5. 让学习更高效 — 角色索引 ↔ 家族树 双向跳转，形成知识网络

这个系统不是一个通用知识库，而是一个服务于特定课程、特定教材、特定教学
目标的精准教育工具。
